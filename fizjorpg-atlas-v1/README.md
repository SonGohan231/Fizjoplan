# FizjoRPG — Atlas of Knowledge

Grywalny vertical slice: 50% roguelike/dungeon crawler, 25% JRPG, 25% długoterminowe RPG/MMO.

Zawiera 8 światów wiedzy, proceduralne lochy, przeciwników i bossów, skrzynie i sekrety, loot i ekwipunek, osobne drzewka wiedzy, kodeks/słownik, questy, zapis postępu oraz naukę wplecioną w walkę. Światy obejmują fizjoterapię/testy, anatomię, fizjologię, psychologię, medycynę bez farmakologii, fizykę, naturę i ciekawostki.

v1.1 zawiera osadzone efekty Mirelo: cios, skrzynia, sekret, level-up i wejście bossa. Muzyka jest proceduralna WebAudio i zmienia charakter zależnie od świata.

Treści kliniczne i medyczne są edukacyjne; gra nie jest narzędziem do podejmowania decyzji diagnostycznych ani terapeutycznych dla konkretnego pacjenta.
